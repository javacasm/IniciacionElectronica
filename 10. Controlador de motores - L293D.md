# Lección 10: Controlador de Motores L293D

## Objetivos

- Comprender el funcionamiento del **L293D** como controlador de motores DC.
- Conocer sus prestaciones, pines, limitaciones y utilidad en proyectos de robótica y automatización.
- Aprender a conectar y controlar motores DC con el L293D desde una fuente de alimentación y señales digitales.
- Construir circuitos prácticos con ejemplos de complejidad progresiva, incluyendo diagramas esquemáticos.

## Conceptos Clave

![[l293d.png]]

- **L293D**: Es un **controlador de motores DC de doble canal (dual H-bridge)** integrado en un solo chip DIP-16. Permite controlar hasta **2 motores DC** de forma independiente, con dirección (adelante/atrás) y velocidad (mediante PWM), usando señales digitales de bajo voltaje (como de una Raspberry Pi Pico o Arduino).
    - **Funcionamiento**: Contiene **cuatro puentes H** (dos por motor), formados por transistores internos. Un puente H permite invertir la polaridad del motor para cambiar de dirección. El L293D incluye **diodos de protección** (flyback) internos para corrientes inductivas.
    - **Prestaciones principales**:
        - **Voltaje de motor (Vs)**: 4.5V a 36V (ideal para motores de 6V-12V).
        - **Voltaje de lógica (Vss)**: 4.5V a 7V (típicamente 5V).
        - **Corriente por canal**: Hasta **600mA continuo**, 1.2A pico (por motor).
        - **Frecuencia PWM**: Hasta ~5kHz (buena respuesta para control de velocidad).
        - **Caída de voltaje**: ~1.8V-2.0V por canal (reduce voltaje efectivo al motor).
        - **Disipación térmica**: Genera calor; usar disipador si >500mA.
        - **Protección**: Diodos internos, entrada de habilitación (enable) por canal.
    - **Utilidad y Usos**:
        - Control de motores en **robots móviles**, carros RC, brazos robóticos.
        - Accionamiento de **cargas inductivas** (motores paso a paso pequeños, solenoides).
        - Proyectos educativos con **Raspberry Pi Pico**, Arduino, ESP32.
        - Alternativa económica a controladores más avanzados (como TB6612FNG o DRV8833).

### Pinout del L293D (DIP-16)

|Pin|Nombre|Función|
|---|---|---|
|1|**Enable 1,2**|Habilita canales 1 y 2 (HIGH = activo, PWM para velocidad)|
|2|**Input 1**|Entrada digital canal 1 (HIGH/LOW para dirección)|
|3|**Output 1**|Salida al motor A (terminal 1)|
|4|**GND**|Tierra (lógica)|
|5|**GND**|Tierra (lógica)|
|6|**Output 2**|Salida al motor A (terminal 2)|
|7|**Input 2**|Entrada digital canal 1|
|8|**Vs**|Alimentación del motor (4.5V-36V)|
|9|**Enable 3,4**|Habilita canales 3 y 4|
|10|**Input 3**|Entrada digital canal 2|
|11|**Output 3**|Salida al motor B (terminal 1)|
|12|**GND**|Tierra (potencia)|
|13|**GND**|Tierra (potencia)|
|14|**Output 4**|Salida al motor B (terminal 2)|
|15|**Input 4**|Entrada digital canal 2|
|16|**Vss**|Alimentación lógica (5V)|

> **Nota**: Los GND (pines 4,5,12,13) deben conectarse todos a tierra común.

## Actividad Práctica 1: Control Básico de un Motor (Dirección)

**Objetivo**: Encender un motor en una dirección y luego invertirlo.

1. **Conexión del circuito**:
    
    - Alimentación: Vss (pin 16) → 5V, Vs (pin 8) → 6V-12V, GND comunes.
    - Enable 1,2 (pin 1) → 5V (siempre activo).
    - Input 1 (pin 2) → GPIO de Pico (e.g., GP0).
    - Input 2 (pin 7) → GPIO de Pico (e.g., GP1).
    - Output 1 y 2 → terminales del motor A.
    - GND del motor → GND común.
2. **Diagrama Esquemático**:
    
    ```
    +5V ----o---- [Pin 16 Vss]
            |
    +12V ---o---- [Pin 8 Vs]
            |
    GND ----o---- [Pines 4,5,12,13]
    
    +5V ------------ [Pin 1 Enable 1,2]
    
    GP0 (Pico) ------ [Pin 2 Input 1]
    GP1 (Pico) ------ [Pin 7 Input 2]
    
    Motor A + -------- [Pin 3 Output 1]
    Motor A - -------- [Pin 6 Output 2]
    ```
    
3. **Lógica de Control**:
    
    |Input 1|Input 2|Dirección|
    |---|---|---|
    |HIGH|LOW|Adelante|
    |LOW|HIGH|Atrás|
    |LOW|LOW|Frenado|
    |HIGH|HIGH|Frenado|
    
4. **Código MicroPython (Pico)**:
    
    ```python
    from machine import Pin
    from time import sleep
    
    in1 = Pin(0, Pin.OUT)
    in2 = Pin(1, Pin.OUT)
    
    # Adelante
    in1.value(1); in2.value(0); sleep(2)
    # Atrás
    in1.value(0); in2.value(1); sleep(2)
    # Parar
    in1.value(0); in2.value(0)
    ```
    
5. **Prueba**: El motor gira en ambas direcciones.

## Actividad Práctica 2: Control de Velocidad con PWM

**Objetivo**: Variar la velocidad del motor usando PWM en el pin Enable.

1. **Conexión**:
    
    - Mismo que antes, pero **Enable 1,2 (pin 1)** → GPIO con PWM (e.g., GP2).
2. **Diagrama Esquemático** (actualizado):
    
    ```
    GP2 (PWM) ------ [Pin 1 Enable 1,2]
    ```
    
3. **Código MicroPython**:
    
    ```python
    from machine import Pin, PWM
    from time import sleep
    
    enable = PWM(Pin(2))
    enable.freq(1000)  # 1kHz
    in1 = Pin(0, Pin.OUT)
    in2 = Pin(1, Pin.OUT)
    
    in1.value(1); in2.value(0)  # Adelante
    for duty in range(0, 65536, 1000):
        enable.duty_u16(duty)
        sleep(0.01)
    ```
    
4. **Prueba**: Motor acelera suavemente.

## Actividad Práctica 3: Control Bidireccional de Dos Motores

**Objetivo**: Controlar dos motores (e.g., robot diferencial).

![[l293d_2motores.png]]

1. **Conexión**:
    
    - Motor A: Canales 1-2 (como antes).
    - Motor B: Canales 3-4.
        - Input 3 (pin 10) → GP3
        - Input 4 (pin 15) → GP4
        - Enable 3,4 (pin 9) → GP5 (PWM)
        - Output 3 y 4 → Motor B
2. **Diagrama Esquemático** (resumen):
    
    ```
    Motor A: GP0, GP1, GP2 (PWM)
    Motor B: GP3, GP4, GP5 (PWM)
    ```
    
3. **Código MicroPython**:
    
    ```python
    # Función para controlar un motor
    def motor_control(in1, in2, enable, speed, direction):
        enable.duty_u16(int(speed * 65535))
        if direction == 'forward':
            in1.value(1); in2.value(0)
        elif direction == 'backward':
            in1.value(0); in2.value(1)
        else:
            in1.value(0); in2.value(0)
    
    # Ejemplo: Robot gira a la derecha
    motor_control(Pin(0), Pin(1), PWM(Pin(2)), 0.7, 'forward')
    motor_control(Pin(3), Pin(4), PWM(Pin(5)), 0.7, 'backward')
    ```
    
4. **Prueba**: Robot gira, avanza, retrocede.

## Actividad Práctica 4: Control con Interruptores Manuales (Sin Microcontrolador)

**Objetivo**: Controlar dirección con interruptores físicos.

1. **Conexión**:
    
    - Enable 1,2 → +5V (siempre activo).
    - Input 1 → Interruptor a +5V.
    - Input 2 → Otro interruptor a +5V.
    - Salidas → Motor.
2. **Diagrama Esquemático**:
    
    ```
    +5V ---[Interruptor 1]--- [Pin 2 Input 1]
    +5V ---[Interruptor 2]--- [Pin 7 Input 2]
    ```
    
3. **Prueba**: Activar un interruptor = una dirección.

- Alta caída de voltaje → menor eficiencia.
- Se calienta → necesita disipador o ventilación.
- Corriente limitada → no para motores grandes.
- Alternativas modernas: **TB6612FNG**, **DRV8833**, **L298N** (con disipador).

# Apéndice: El Puente H en Detalle

## Introducción

El **puente H** (H-bridge) es un circuito electrónico fundamental para el control bidireccional de motores DC y otras cargas inductivas. Su nombre proviene de la forma en "H" que adoptan los cuatro interruptores (generalmente transistores) cuando se representan esquemáticamente. Este apéndice explica en detalle su **funcionamiento, componentes, modos de operación, aplicaciones y consideraciones prácticas**, ampliando el uso visto en la Lección 10 con el L293D.

---

## Estructura Básica del Puente H

Un puente H está compuesto por **cuatro interruptores** (S1, S2, S3, S4) conectados entre la fuente de alimentación (+V) y tierra (GND), con el motor colocado en el centro, formando una "H":

```
       S1          S3
        o----------o
        |          |
+V -----|          |----- GND
        |   MOTOR  |
        |          |
        o----------o
       S2          S4
```

- **S1 y S4**: Conectan el motor en una polaridad (adelante).
- **S2 y S3**: Conectan el motor en polaridad inversa (atrás).
- **Motor**: Carga inductiva en el centro.

> **Importante**: **Nunca** se deben activar S1+S2 o S3+S4 al mismo tiempo → **cortocircuito** (shoot-through).

---

## Modos de Operación

|Modo|S1|S2|S3|S4|Efecto en Motor|
|---|---|---|---|---|---|
|**Adelante**|ON|OFF|OFF|ON|+V en terminal A, GND en B|
|**Atrás**|OFF|ON|ON|OFF|GND en A, +V en B|
|**Freno**|OFF|ON|OFF|ON|Ambos terminales a GND → freno corto|
|**Freno**|ON|OFF|ON|OFF|Ambos terminales a +V → freno corto|
|**Flote**|OFF|OFF|OFF|OFF|Motor en inercia (sin freno)|

### Explicación Detallada

1. **Adelante**: Corriente fluye de S1 → Motor → S4 → GND.
2. **Atrás**: Corriente fluye de S3 → Motor → S2 → GND.
3. **Freno (corto)**: Ambos terminales del motor conectados al mismo potencial → la inductancia genera corriente de frenado.
4. **Flote**: Motor desacelera por inercia, sin disipación activa.

---

## Implementación con Transistores

En la práctica, los interruptores son **transistores** (BJT o MOSFET):

### Con BJT (como en L293D interno)

```
       Q1 (NPN)     Q3 (NPN)
        o----------o
        |          |
+V -----|          |----- GND
        |   MOTOR  |
        |          |
        o----------o
       Q2 (PNP)     Q4 (PNP)
```

- Q1 y Q4: ON → adelante.
- Diodos flyback necesarios (internos en L293D).

### Con MOSFET (más eficiente)

```
       Q1 (P-ch)    Q3 (P-ch)
        o----------o
        |          |
+V -----|          |----- GND
        |   MOTOR  |
        |          |
        o----------o
       Q2 (N-ch)    Q4 (N-ch)
```

- Menor caída de voltaje (~0.1V vs 2V en BJT).
- Mayor eficiencia, menos calor.

---

## Control de Velocidad: PWM

La velocidad se controla aplicando **PWM** (modulación por ancho de pulso) en los pines **Enable** o directamente en las entradas:

- **PWM en Enable** (L293D): Ambos inputs fijos (HIGH/LOW), Enable con PWM → velocidad variable, dirección fija.
- **PWM en Inputs**: Alternar entre "adelante" y "flote" → control fino, pero más complejo.

**Frecuencia recomendada**: 1kHz - 20kHz (evita zumbido audible).

---

## Diodos Flyback (Protección)

Los motores son **cargas inductivas** → al apagar, generan picos de voltaje inverso (Lenz).

**Solución**: **Diodos flyback** en paralelo con cada transistor:

```
       S1
+V ---|>---o--- MOTOR ---o---|<---+V
           |             |
          GND           GND
```

- En L293D: **integrados**.
- En circuitos discretos: **obligatorios** (1N4001, 1N5817).

## Ejemplo Práctico: Puente H con L293D (Canal 1)

```
Pin 1 (Enable) → PWM (velocidad)
Pin 2 (Input 1) → GPIO A
Pin 7 (Input 2) → GPIO B
Pin 3 & 6 → Motor
```

|Enable|Input1|Input2|Resultado|
|---|---|---|---|
|PWM|HIGH|LOW|Adelante + velocidad|
|PWM|LOW|HIGH|Atrás + velocidad|
|HIGH|LOW|LOW|Freno|
|LOW|X|X|Flote|

## Aplicaciones Comunes

|Aplicación|Uso del Puente H|
|---|---|
|**Robots móviles**|Control diferencial de dos motores|
|**Carros RC**|Dirección y velocidad|
|**Brazo robótico**|Control preciso de actuadores|
|**Ventiladores**|Velocidad variable|
|**Cintas transportadoras**|Arranque/paro/inversión|

---

## Consideraciones de Diseño

|Factor|Recomendación|
|---|---|
|**Caída de voltaje**|L293D: ~2V → usar motor con voltaje mayor|
|**Calor**|>500mA → disipador o ventilador|
|**Corriente pico**|No exceder 1.2A (L293D)|
|**Frecuencia PWM**|1-20kHz (evitar audible)|
|**Protección**|Diodos, fusibles, limitación de corriente|

---

## Alternativas al L293D

|Chip|Ventajas|Desventajas|
|---|---|---|
|**TB6612FNG**|1.2A, baja caída (~0.5V), eficiente|SMD (difícil soldar)|
|**DRV8833**|1.5A, bajo consumo, protección térmica|Solo 2 canales|
|**L298N**|2A por canal, robusto|Alta caída (~2V), mucho calor|
|**MOSFET discretos**|Máxima eficiencia, alta corriente|Diseño complejo|

---

## Conclusión

El **puente H** es la base del control bidireccional de motores. El **L293D** lo implementa de forma integrada y sencilla, ideal para principiantes. Comprender su funcionamiento permite:

- Diagnosticar fallos (motor no gira, sobrecalentamiento).
- Escalar a controladores más avanzados.
- Diseñar sistemas robóticos robustos.

> **Consejo práctico**: Siempre mide la corriente del motor con un multímetro en serie para evitar sobrecargas.
