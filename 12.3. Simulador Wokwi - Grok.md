### Tutorial Detallado de Wokwi: El Simulador Online para Electrónica e IoT

En este tutorial exhaustivo, te guiaré paso a paso por el uso de **Wokwi** (disponible en https://wokwi.com/), una herramienta poderosa para simular proyectos de electrónica, microcontroladores y sistemas IoT directamente en tu navegador. Wokwi es ideal para principiantes, estudiantes, makers y profesionales que quieren prototipar sin hardware físico, ahorrando tiempo y dinero. Cubriremos desde lo básico hasta proyectos avanzados, compararemos sus capacidades con otros simuladores online populares y analizaremos su esquema de precios actualizado a 2025.

Este tutorial está dividido en secciones para facilitar la lectura. Necesitarás un navegador web moderno (como Chrome o Firefox) y una cuenta gratuita en Wokwi (opcional, pero recomendada para guardar proyectos).

#### 1. ¿Qué es Wokwi y por qué usarlo?
Wokwi es un simulador online de electrónica y sistemas embebidos que permite diseñar circuitos, escribir código y simular comportamientos en tiempo real. Soporta placas como Arduino (UNO, Mega, Nano), ESP32, STM32, Raspberry Pi Pico y más. Sus fortalezas incluyen simulación de WiFi, sensores, displays y protocolos IoT (como MQTT y HTTP), todo sin instalaciones ni hardware real.

**Ventajas clave:**
- **Accesible**: Todo en el navegador, sin descargas.
- **Colaborativo**: Comparte proyectos con un enlace.
- **Seguro**: No "quemas" componentes virtuales.
- **Educativo**: Integra editor de código con autocompletado y depurador interactivo.

Ahora, ¡manos a la obra!

#### 3. Creación de un Proyecto Básico: LED Parpadeante con Arduino UNO
Empecemos con un clásico: un LED que parpadea usando Arduino UNO.

1. **Selecciona la placa**:
   - Clic en "New Project".
   - Elige "Arduino UNO" de la lista (o busca por nombre).
   - Se abre el workspace: un lienzo dividido en tres paneles principales.
     - **Editor de diagrama**: Donde arrastras componentes y cables.
     - **Editor de código**: Para escribir sketches en C++ (estilo Arduino IDE).
     - **Simulador/Serial Monitor**: Para ejecutar y ver salidas.

2. **Agrega componentes**:
   - Clic en el ícono "+" (púrpura) en el panel derecho.
   - Busca "LED" en la biblioteca de partes y arrástralo al lienzo.
   - Agrega una "Resistor" (220Ω recomendada) y conéctala en serie con el LED.
   - Conecta el ánodo del LED (pata larga) al pin digital 13 del Arduino vía resistor.
   - Conecta el cátodo (pata corta) a GND (tierra).

   **Conexiones**:
   - Arrastra cables desde los pines: Pin 13 → Resistor → LED → GND.
   - Usa el zoom (rueda del mouse) para precisión. No puedes cambiar colores de cables gráficamente, pero es intuitivo.

3. **Escribe el código**:
   - En el editor de código (izquierda), borra el template y pega esto:
     ```cpp
     void setup() {
       pinMode(13, OUTPUT);  // Configura pin 13 como salida
     }

     void loop() {
       digitalWrite(13, HIGH);  // Enciende LED
       delay(1000);             // Espera 1 segundo
       digitalWrite(13, LOW);   // Apaga LED
       delay(1000);             // Espera 1 segundo
     }
     ```
   - Wokwi incluye autocompletado (presiona Ctrl+Espacio) y resalta errores.

4. **Ejecuta la simulación**:
   - Clic en el botón "Start Simulation" (▶️ verde).
   - ¡El LED parpadeará! Observa el Serial Monitor abajo para depuración (agrega `Serial.println("Hola");` en loop() para ver texto).
   - Pausa (⏸️), reinicia (↻) o ajusta velocidad con el slider.

5. **Guarda y comparte**:
   - Clic "Save" (disquete). Proyectos gratuitos son públicos; pagos permiten privados.
   - Copia el enlace para compartir. Otros pueden editar en tiempo real.

**Tiempo estimado**: 5-10 minutos. **Problemas comunes**: Verifica conexiones (cables rojos para +5V, negros para GND).

#### 4. Proyecto Intermedio: Sensor de Temperatura con ESP32 y Display OLED
Ahora, algo más avanzado: Lee temperatura con DHT11 y muéstrala en un OLED SSD1306 vía I2C.

1. **Nueva placa**: Crea proyecto con "ESP32 DevKit V1".
2. **Componentes**:
   - "+" → Agrega "DHT11" (sensor), "SSD1306" (display OLED 128x64).
   - Conexiones:
     - DHT11: Data a pin GPIO4, VCC a 3.3V, GND a GND.
     - OLED: SDA a GPIO21, SCL a GPIO22, VCC a 3.3V, GND a GND.
3. **Código** (instala librerías vía #include; Wokwi soporta DHT y Adafruit SSD1306):
     ```cpp
     #include <DHT.h>
     #include <Adafruit_GFX.h>
     #include <Adafruit_SSD1306.h>

     #define DHTPIN 4
     #define DHTTYPE DHT11
     DHT dht(DHTPIN, DHTTYPE);
     Adafruit_SSD1306 display(128, 64, &Wire, -1);

     void setup() {
       Serial.begin(115200);
       dht.begin();
       if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
         Serial.println("OLED falló");
         for (;;);
       }
       display.clearDisplay();
     }

     void loop() {
       float temp = dht.readTemperature();
       display.clearDisplay();
       display.setTextSize(2);
       display.setTextColor(WHITE);
       display.setCursor(0, 0);
       display.print("Temp: ");
       display.print(temp);
       display.print(" C");
       display.display();
       delay(2000);
     }
     ```
4. **Simula**: El display mostrará la temperatura simulada (alrededor de 25°C por defecto). Usa el depurador para pausar en líneas específicas.

**Tip**: Para WiFi, agrega `WiFi.begin("SSID", "pass");` y simula conexiones HTTP/MQTT (solo en planes pagos).

#### 5. Características Avanzadas de Wokwi
Wokwi brilla en lo avanzado. Aquí un resumen:

| Característica | Descripción | Ejemplo de Uso |
|---------------|-------------|----------------|
| **Simulación de Periféricos** | UART, I2C, SPI, SD Card, Motores, Sensores (DHT, Ultrasonic, etc.). | Analiza señales con Logic Analyzer (exporta a VCD para PulseView). |
| **IoT y Redes** | WiFi real (HTTP, MQTT, NTP) en ESP32. | Conecta a APIs como OpenWeatherMap para datos reales. |
| **Depuración** | Debugger interactivo (step-by-step), GDB para avanzados. | Pausa código y inspecciona variables. |
| **Librerías y Archivos** | Soporte para todas las libs Arduino; sube binarios/custom chips (pagado). | Proyectos multi-archivo (.h, .cpp). |
| **Integraciones** | VS Code extension, CI/CD (GitHub Actions). | Simula desde tu IDE. |
| **Colaboración** | Proyectos compartibles, comunidad Discord. | Edita en equipo. |
| **Otras** | Displays (OLED, TFT), NeoPixels, FastLED; Chips API para custom parts. | Crea LEDs RGB animados. |

**Limitaciones**: No simula física compleja (e.g., electromagnetismo) ni todos los features de hardware real (ver docs para detalles).

#### 6. Comparación de Capacidades con Otros Simuladores Online
Wokwi destaca en simulación de microcontroladores e IoT, pero veamos cómo se compara con alternativas populares en 2025 (basado en reseñas de sitios como Electronics-Lab, Reddit y eTechnophiles). Usé criterios como soporte de hardware, facilidad, IoT, precios y rendimiento.

| Simulador | Soporte Principal | Fortalezas | Debilidades | Precio | vs. Wokwi |
|-----------|-------------------|------------|-------------|--------|-----------|
| **Wokwi** | Arduino, ESP32, STM32, RP Pico; C++/MicroPython/Rust. | IoT (WiFi/MQTT), depurador avanzado, libs completas, browser-based. Rápido y colaborativo. | Curva de aprendizaje media; no para analog puro. | Gratis básico; $7/mes premium. | - (Referencia) |
| **Tinkercad Circuits** (Autodesk) | Arduino UNO básico; bloques + C++. | Súper intuitivo para principiantes, drag-and-drop, integración 3D. | Limitado a UNO; no ESP32/WiFi; libs básicas. Lento en proyectos grandes. | Gratis total. | Wokwi es más avanzado para IoT y multi-plataforma; Tinkercad mejor para kids/escuelas. |
| **Falstad Circuit Simulator** | Circuitos analógicos/digitales genéricos. | Visualización en tiempo real (ondas, corrientes como "puntos"). Rápido para experimentos. | No microcontroladores ni código; solo breadboard simple. | Gratis total. | Wokwi integra código + simulación; Falstad para analog rápido, pero Wokwi gana en embebidos. |
| **CircuitLab** | Esquemáticos SPICE; analógicos/digitales. | Preciso para simulación matemática; exporta a PDF/SVG. | No microcontroladores/IoT; interfaz web pero paga para full. | Gratis limitado; $10+/mes pro. | Wokwi más enfocado en hardware real; CircuitLab para ingenieros analógicos puros. |
| **Proteus VSM (Online/Trial)** | Microcontroladores (Arduino/PIC), PCB design. | Osciloscopios, lógica avanzada; integra simulación + PCB. | No fully online (descarga); caro; curva alta. | Trial gratis; $500+ licencia anual. | Wokwi gratis/online para prototipos rápidos; Proteus para pros con PCB, pero Wokwi más accesible. |

**Conclusión de comparación**: Wokwi es el **mejor para IoT y embebidos en 2025** por su soporte ESP32/WiFi y actualizaciones constantes (e.g., debugger GDB). Supera a Tinkercad en profundidad, a Falstad en código, y es más asequible que Proteus. Si buscas analog puro, Falstad o CircuitLab; para principiantes absolutos, Tinkercad. En reseñas de Reddit y Hackaday, Wokwi puntúa alto por velocidad (compila más rápido que hardware real) y comunidad.

#### 7. Estudio del Esquema de Precios de Wokwi (2025)
Wokwi es **gratis para uso personal**, pero ofrece planes pagos para pros/comerciales. Basado en su página de pricing (https://wokwi.com/pricing), aquí un desglose actualizado:

| Plan | Precio | Características Principales | Limitaciones | Ideal Para |
|------|--------|-----------------------------|--------------|------------|
| **Free** | $0/mes | Proyectos públicos, simulación básica, todas las placas/sensores, libs estándar, serial monitor, ejemplos ilimitados. Builds en cola (puede esperar en picos). | Proyectos visibles públicamente; no WiFi/MQTT real, no custom libs/binarios, no privados. | Estudiantes, hobbyists, aprendizaje. |
| **Club (Premium)** | $7/mes o $67/año (ahorro ~20%) | Todo lo free + builds prioritarios (servidores dedicados), proyectos privados/unlisted, upload custom libs (ESP32/Arduino), binarios SD, WiFi simulado (HTTP/MQTT/NTP), voto en features. | Límite en uploads grandes; no enterprise. | Desarrolladores independientes, IoT pros. |
| **Classroom/Education** | Cotización personalizada (gratis para escuelas pequeñas; ~$50/clase/año para grandes). | Licencia grupal, dashboards para maestros, proyectos privados por estudiante, soporte dedicado. | Requiere aprobación. | Educadores, universidades. |
| **Enterprise/CI** | Cotización (desde $50/mes por equipo). | Integración CI/CD (GitHub/GitLab), custom chips, soporte 24/7, unlimited builds. | Mínimo 5 usuarios. | Empresas, testing automatizado. |

**Análisis**:
- **Valor**: El free cubre 80% de usos (e.g., tu LED o DHT). Premium desbloquea IoT real, clave para ESP32 (e.g., APIs externas). En 2025, no hay cambios drásticos; precios estables desde 2023.
- **Pagos**: Vía Paddle (tarjeta/PayPal). Cancelación fácil; trial de 14 días para premium.
- **Comparado**: Más barato que Proteus ($500+) o CircuitLab ($10+/mes), similar a Tinkercad (gratis pero limitado).
- **Consejo**: Empieza free; sube si necesitas privacidad o WiFi. Para detalles, visita https://wokwi.com/pricing.

#### 8. Consejos Avanzados y Recursos
- **Depuración**: Usa breakpoints en código; integra Logic Analyzer para señales I2C/SPI.
- **Proyectos complejos**: Simula SD cards subiendo .bin; crea custom parts con Chips API.
- **Integración VS Code**: Instala la extensión "Wokwi Simulator" para simular desde tu IDE.
- **Comunidad**: Únete a Discord (enlace en docs.wokwi.com) o explora proyectos en wokwi.com/projects.
- **Docs**: https://docs.wokwi.com/ – Guías detalladas, ejemplos y troubleshooting.
- **Actualizaciones 2025**: Soporte mejorado para Rust y más displays; verifica changelog.
