# Tutorial Completo y Detallado de Fritzing (2025)  
Guía paso a paso desde cero hasta proyectos avanzados + comparación con otras herramientas

## ¿Qué es Fritzing y para qué sirve?
Fritzing es un software **open-source** para diseñar, documentar y compartir proyectos electrónicos de forma visual y profesional. Es especialmente querido por makers, educadores, bloggers y creadores de tutoriales porque permite mostrar los circuitos exactamente como se ven en la vida real (vista breadboard), pero también generar esquemáticos limpios y PCBs fabricables.

Sitio oficial: https://fritzing.org  
Descarga directa (gratuita): https://fritzing.org/download

## Instalación (2025)
| Sistema       | Método recomendado                                                                 | Tamaño     |
|---------------|------------------------------------------------------------------------------------|------------|
| Windows 10/11 | Descargar el .exe desde la web oficial                                             | ~300 MB    |
| macOS         | Descargar el .dmg (Intel o Apple Silicon)                                         | ~320 MB    |
| Linux         | AppImage (funciona en cualquier distro) o paquete .deb/.rpm desde la web oficial | ~300 MB    |

Nota: Desde 2023 ya no se distribuye en repositorios oficiales de muchas distros por falta de mantenimiento, así que siempre usa la versión de fritzing.org.

## Interfaz principal (versión 1.0.3 – última estable a diciembre 2025)

Tres vistas principales (pestañas en la parte superior):
1. **Breadboard** → Vista realista (la que más usa todo el mundo para tutoriales).
2. **Schematic** → Esquemático clásico de ingeniería.
3. **PCB** → Diseño de placa de circuito impreso (fabricable en JLCPCB, PCBWay, etc.).

Paneles laterales:
- **Inspector** (derecha): Cambia valores de componentes, colores, notas.
- **Parts / Biblioteca** (derecha abajo): Miles de componentes.
- **Layers** (PCB): Control de capas de cobre, serigrafía, etc.

## Tutorial paso a paso: Desde cero hasta PCB fabricable

### Proyecto ejemplo: Controlador de tiras LED RGB con Arduino Nano + potenciómetro

#### Paso 1 – Crear nuevo proyecto
Archivo → Nuevo → Aceptar plantilla vacía

#### Paso 2 – Vista Breadboard (la más bonita para tutoriales)
1. En la biblioteca busca “Arduino Nano” → arrástralo al centro.
2. Busca “Breadboard” (la grande de 830 puntos) → colócala.
3. Coloca el Nano encima de la breadboard (Fritzing lo alineará automáticamente).
4. Agrega:
   - 1 potenciómetro (busca “potentiometer”)
   - 3 resistencias 220 Ω o 330 Ω
   - 3 MOSFETs IRF520 o lógica con transistor NPN (2N2222 o BC547)
   - 1 tira LED RGB de cátodo común (o 3 LEDs RGB individuales)
   - Cables jumper macho-hembra y macho-macho

#### Paso 3 – Conexiones reales (Breadboard view)
Ejemplo de conexiones típicas:
- Potenciómetro → 5V, GND y wiper a A0 del Nano
- Pin D9 → Resistencia 220 Ω → Gate del MOSFET 1 (canal Rojo)
- Pin D10 → canal Verde
- Pin D11 → canal Azul
- Drain de cada MOSFET → cátodo del color correspondiente
- Source de MOSFETs → GND
- +12V externo → ánodo común de la tira LED

Consejo visual: Usa el botón derecho sobre un cable → “Wire Color” para diferenciar alimentación, señales PWM, etc.

#### Paso 4 – Cambiar a vista Schematic
Haz clic en la pestaña “Schematic”.  
Fritzing intentará auto-generar el esquemático.  
Corrige lo que no te guste:
- Arrastra símbolos para ordenar
- Usa la herramienta “Autoroute” o mueve manualmente los cables para que quede limpio

#### Paso 5 – Diseñar la PCB (¡fabricable!)
1. Ve a la pestaña “PCB”.
2. En el Inspector cambia el tamaño de la placa (ejemplo: 5 × 7 cm).
3. Selecciona todos los componentes → Menú “Routing” → “Move to Bottom Layer” si quieres placa de doble cara.
4. Herramienta “Autoroute” (magia negra):
   - Routing → Autoroute → All components
   - Elige “2 layers” y “Optimize for manufacturability”
5. Corrige manualmente pistas feas con la herramienta “Route manually”.
6. Añade serigrafía:
   - Herramienta Text → escribe tu nombre, versión, web, etc.
   - Herramienta Rectangle para hacer bordes redondeados o logos.

#### Paso 6 – Exportar para fabricación
Export → For Production → Extended Gerber (estándar universal)  
Te genera un .zip con todos los archivos necesarios para JLCPCB, PCBWay, OSH Park, etc.  
Costo típico de 5 unidades de esta placa: 2–5 USD + envío (2025).

#### Paso 7 – Exportar imágenes bonitas para tutoriales/blog
Export → Image → elige PNG o SVG a 600 dpi  
Puedes exportar cada vista por separado (breadboard, schematic, PCB).

## Comparación actualizada 2025 con otras herramientas

| Característica                | Fritzing          | KiCad 8        | EasyEDA / JLCEDA     | Tinkercad Circuits   | Wokwi              |
|----------------------------------|-------------------|----------------|----------------------|----------------------|--------------------|
| Gratis y open-source             | Sí                | Sí             | Gratis (cloud)       | Gratis               | Gratis + premium   |
| Vista breadboard realista        | Excelente         | No             | Básica               | Buena                | Buena              |
| Esquemático profesional          | Bueno             | Excelente      | Muy bueno            | Muy básico           | Básico             |
| Diseño PCB avanzado              | Básico-Medio      | Excelente      | Excelente            | No                   | No                 |
| Fabricación directa (JLCPCB)     | Gerbers manual    | Sí (plugin)    | Integrado            | No                   | No                 |
| Ideal para tutoriales y blogs    | El rey            | No             | Regular              | Bueno                | Bueno              |
| Curva de aprendizaje              | Baja              | Alta           | Media                | Muy baja             | Baja               |
| Offline                          | Sí                | Sí             | No (cloud)           | Sí                   | No (web)           |

Conclusión 2025:  
Fritzing sigue siendo imbatible si tu objetivo es crear tutoriales bonitos, documentación clara o proyectos educativos.  
Para PCBs complejas o producción en serie → KiCad o EasyEDA son superiores.

## Bibliotecas de componentes adicionales (2025
La biblioteca oficial se quedó algo anticuada. Las más usadas por la comunidad:
- Adafruit Fritzing Library → https://github.com/adafruit/Fritzing-Library
- SparkFun Fritzing Parts → https://github.com/sparkfun/Fritzing_Parts
- Frizting (fork mantenido activamente) → https://github.com/frizting/frizting-parts (más actualizado)

Cómo instalar:
1. Descarga el .zip
2. En Fritzing: Ayuda → “Open Parts Folder”
3. Copia los archivos .fzpz dentro
4. Reinicia Fritzing

## Consejos profesionales para que tus proyectos queden perfectos
- Usa siempre resistencias de 1/4W (las azules) en vista breadboard → quedan más realistas.
- Activa “Show ratsnest lines” en PCB para ver conexiones pendientes.
- Usa la herramienta “Design Rules Check (DRC) antes de exportar Gerbers.
- Para fotos ultra-realistas: exporta PNG a 300–600 dpi y pon fondo transparente.
