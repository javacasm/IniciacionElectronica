## 🚀 Empezando con Wokwi

1. **Accede a Wokwi:**
    
    - Ve al sitio web oficial: [https://wokwi.com/](https://wokwi.com/).
        
2. **Crea una Cuenta (Opcional pero Recomendado):**
    
    - Puedes usar el simulador sin una cuenta, pero crear una (gratuita) te permite **guardar tus proyectos** y acceder a ellos desde cualquier lugar.
        
3. **Inicia un Nuevo Proyecto:**
    
    - En la página principal, haz clic en **"Start a new project"** o selecciona una plantilla específica (como "Arduino Uno", "ESP32", etc.).
        
    - Esto abrirá la interfaz del simulador, generalmente dividida en tres áreas principales: **Diagrama**, **Editor de Código**, y **Consola**.
        

---

## 💻 Interfaz Principal

La interfaz de Wokwi está diseñada para que puedas ver el hardware y el código al mismo tiempo:

- ### 🛠️ Área del Diagrama (Izquierda)
    
    - Aquí es donde se **simula el hardware** (la placa de microcontrolador, LEDs, sensores, etc.).
        
    - Puedes **arrastrar y soltar componentes** y conectarlos con **cables virtuales**.
        
- ### 📝 Editor de Código (Centro)
    
    - Es un editor de texto donde **escribes o pegas tu código** (generalmente en C++ para Arduino/ESP32, o MicroPython).
        
    - Tiene resaltado de sintaxis para facilitar la escritura.
        
- ### 📊 Consola/Salida (Abajo)
    
    - Esta ventana muestra la **salida serial** del microcontrolador (lo que imprimes con `Serial.print()`).
        
    - También muestra cualquier mensaje de error o información de compilación.
        

---

## 🧩 Construyendo el Circuito

1. **Añadir Componentes:**
    
    - Haz clic en el botón **"+"** (generalmente ubicado cerca del área del diagrama, a la izquierda o en la parte superior).
        
    - Se abrirá el **"Parts Library"** (Biblioteca de Componentes).
        
    - **Busca** el componente que necesitas (ej: `LED`, `resistor`, `pushbutton`, `DHT22`).
        
    - Haz clic en él para **añadirlo** a tu diagrama.
        
2. **Conexión de Componentes (Cableado):**
    
    - Haz clic en el **pin de un componente** (ej: un pin digital en el Arduino) y arrastra el ratón.
        
    - Haz clic en el **pin del otro componente** donde quieres conectarlo (ej: la pata de un LED).
        
    - Esto crea un **cable virtual**. Puedes **cambiar el color** del cable haciendo clic derecho sobre él.
        
3. **Configuración de Componentes:**
    
    - Algunos componentes, como las resistencias o los condensadores, tienen propiedades que puedes cambiar.
        
    - Haz clic derecho sobre el componente en el diagrama y selecciona **"Edit Part"** (o similar) para ajustar sus valores (ej: cambiar una resistencia de $1k\Omega$ a $220\Omega$).
        

---

## ✍️ Programación y Simulación

1. **Escribir/Pegar el Código:**
    
    - Asegúrate de que tu código esté en el **Editor de Código** (generalmente llamado `sketch.ino` para Arduino).
        
2. **Iniciar la Simulación:**
    
    - Haz clic en el botón verde de **"Play"** o **"Run"** (símbolo de triángulo $\triangleright$) en la parte superior de la interfaz.
        
    - Wokwi **compilará** y **cargará** el código en el microcontrolador virtual.
        
3. **Interacción:**
    
    - Una vez que la simulación esté en marcha, puedes **interactuar** con los componentes en el diagrama.
        
    - Por ejemplo, haz clic en un **botón pulsador** para cerrarlo o mira la **pantalla LCD** para ver los mensajes.
        
    - Revisa la **Consola** para ver la salida serial de tu programa.
        
4. **Detener la Simulación:**
    
    - Haz clic en el botón de **"Stop"** (símbolo de cuadrado $\square$) para detener el proceso y poder editar el código o el circuito.

## 💾 Gestión de Proyectos

- **Guardar:** Si has iniciado sesión, tu proyecto se **guarda automáticamente** en tiempo real.
    
- **Compartir:** Wokwi genera una **URL única** para cada proyecto. Puedes compartir este enlace con cualquiera para que pueda ver y simular tu trabajo.
    
- **Buscar Proyectos:** La mayoría de los proyectos en Wokwi son públicos, y puedes **buscar ejemplos** de la comunidad para aprender y reutilizar código o diagramas.

---

### 🔍 Puntos Clave del Esquema de Precios

1. **Gratuito para Uso Personal y Open Source:**
    
    - El plan **Community** es muy generoso, ofreciendo **simulaciones ilimitadas** para proyectos que son públicos (visibles para la comunidad). Es ideal para estudiantes, aficionados y desarrolladores que comparten su trabajo.
        
    - Los usuarios gratuitos tienen un límite de **50 minutos de tiempo de simulación** al mes para tareas de Integración Continua (CI/CD) o simulación avanzada.
        
2. **"Fast Build Minutes" y Límites:**
    
    - Los planes de pago introducen el concepto de **"Fast Build Minutes"** (minutos de compilación rápida). Estos minutos se consumen en tareas que requieren recursos más intensivos o prioridad, como el uso de Wokwi en flujos de trabajo de GitHub Actions (CI/CD).
        
    - El tiempo de simulación se refiere al tiempo total que la simulación está activa en los servicios de Wokwi (por ejemplo, en tus tests automatizados).
        
3. **Proyectos No Listados (Unlisted):**
    
    - A partir del plan **Hobby**, puedes crear proyectos que no son públicos, sino **no listados**. Esto significa que solo aquellos con el enlace directo pueden acceder a ellos, ofreciendo un nivel de privacidad.
        
4. **Uso Comercial y Equipos:**
    
    - El plan **Wokwi Pro** está diseñado específicamente para empresas, ofreciendo facturación por puesto (`$25/seat/mo`) y características avanzadas para el desarrollo profesional, como soporte para entornos sin conexión (offline) en VS Code.
        

**En resumen:**

- **Si eres un aficionado o estudiante y no te importa que tus proyectos sean públicos, el plan "Community" es totalmente funcional.**
    
- **Si necesitas privacidad, cargar librerías complejas, o usar Wokwi para desarrollo profesional, necesitarás uno de los planes de pago.**
    

Puedes consultar la información directamente en la página de precios de Wokwi.
